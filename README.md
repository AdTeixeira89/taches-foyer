# Mon Foyer

Application familiale : tâches, calendrier partagé, idées avec dictée vocale, points, défis, bonus et roulette des récompenses.

Une seule page HTML autonome (`index.html`), sans dépendance à installer.

## Utilisation

- **Version partagée en direct** : la page publiée sur claude.ai (lien privé). La synchronisation entre téléphones utilise la base de données intégrée à cette page.
- **Depuis ce dépôt (GitHub Pages ou fichier local)** : l'application fonctionne en mode local. Les données restent sur l'appareil et ne sont pas partagées entre les membres de la famille.

## Avoir les mêmes données pour toute la famille

1. Tout le monde ouvre la version familiale : https://claude.ai/artifact/XyDceVrGTqUB2qQG4faGsM (chacun connecté à son compte claude.ai).
2. Le propriétaire invite chaque membre **par e-mail** depuis le menu « Partager » de la page, avec le niveau **Éditeur**.
3. Ne pas activer le partage par lien public : les personnes arrivant par un lien public, ou invitées avec un autre niveau, ne peuvent que lire.

Ouverte depuis GitHub Pages ou en fichier local, la page affiche un lien vers cette version familiale.
