# Mon Foyer

Application familiale : tâches, calendrier partagé, idées avec dictée vocale, points, défis, bonus et roulette des récompenses.

Une seule page HTML autonome (`index.html`), sans dépendance à installer.

## Utilisation

- **Version partagée en direct** : la page publiée sur claude.ai (lien privé). La synchronisation entre téléphones utilise la base de données intégrée à cette page.
- **Depuis ce dépôt (GitHub Pages ou fichier local)** : l'application fonctionne en mode local. Les données restent sur l'appareil et ne sont pas partagées entre les membres de la famille.

## Mise en ligne sur GitHub Pages

Settings, Pages, Deploy from a branch, branche `main`, dossier `/ (root)`.

## Remarques

- Indépendante de toute application de budget : données propres.
- Aucune clé ni donnée personnelle dans ce dépôt.
